# flame_studio_annotations

Annotations that mark your Flame components and behaviors for
Flame Studio: `@StudioBehavior`, `@StudioComponent` and
`@Editable`.

Pure Dart with no dependencies. You normally don't depend on it directly:
`flame_studio_runtime` re-exports it.

> **Status:** skeleton. The annotations arrive in v0.1 (see
> [`docs/project-plan.md`](../../docs/project-plan.md) §6.1).
