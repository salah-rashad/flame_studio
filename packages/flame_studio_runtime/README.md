# flame_studio_runtime

Loads scenes made in Flame Studio into your Flame game:
`StudioScene.load`, the generated Registry interface, asset loading and
Hot-swap during development.

Add it as a regular dependency; it re-exports `flame_studio_annotations`.
Requires Flame ≥ 1.36.

> **Status:** skeleton. The Runtime API arrives in v0.1 (see
> [`docs/project-plan.md`](../../docs/project-plan.md) §6.2).
