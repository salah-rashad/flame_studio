# pyro_runtime

Loads scenes made in Pyro into your Flame game:
`PyroScene.load`, the generated Registry interface, asset loading and
Hot-swap during development.

Add it as a regular dependency; it re-exports `pyro_annotations`.
Requires Flame ≥ 1.36.

> **Status:** skeleton. The Runtime API arrives in v0.1 (see
> [`docs/project-plan.md`](../../docs/project-plan.md) §6.2).
